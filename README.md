# QuanVaulte — EdTech Mobile Application

A cross-platform mobile app connecting students, parents, and teachers for academic tracking, assignments, and communication.

## 📱 Demo
[Watch Demo Video](YOUR_YOUTUBE_LINK_HERE)

## ✨ Features
- Multi-role authentication — Student, Parent, and Teacher dashboards
- Assignment tracking and academic progress monitoring
- Parent-teacher communication channel
- Class and subject management for teachers
- Cross-platform: Android & iOS

## 🛠 Tech Stack
- React Native, Expo, TypeScript
- Expo Router (scalable navigation)
- REST APIs
- Expo EAS (build & release)

## 🏗 Architecture Highlights
- **Multi-role auth system** — single codebase, three distinct user experiences
- **Type-safe throughout** — fully written in TypeScript for reliability and scale
- **Expo Router** — file-based routing for clean, maintainable navigation
- **Optimized rendering** — efficient state management for smooth performance
